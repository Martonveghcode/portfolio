Handwriting generation pipeline

Una extension/pipeline para "My Text in Your Handwriting" de Thaines. Incluye formateo de texto, soporte limitado de Unicode->ASCII, un pipeline de formateo para impresion y macros/utilidades para procesar datos de entrenamiento, ademas de una hoja de entrenamiento recomendada.

Las muestras escaneadas necesitan limpieza y separación antes del entrenamiento, y el texto objetivo debe ajustarse al conjunto de caracteres disponible. El repositorio mantiene estas herramientas junto al flujo de formato para repetir el proceso en documentos posteriores.

La síntesis genera la escritura, pero todavía no una hoja lista para imprimir. La fase de formato coloca las líneas en una página, aplica espaciado y resuelve algunos caracteres acentuados mediante una capa de compatibilidad ASCII limitada.

El modelo y la síntesis principal siguen perteneciendo al proyecto original. Este repositorio añade preparación de datos, compatibilidad de texto, formato repetible, salida imprimible y notas de entorno para el antiguo conjunto de herramientas Python 2.
