Macro Recorder +

El grabador de macros que realmente funciona. App de escritorio para Windows hecha con Python y PySide6 para grabar, editar, reproducir y exportar flujos de teclado y raton. Exporta a .py y .exe para que tus macros se ejecuten sin esfuerzo. Totalmente de codigo abierto y gratis.

Los eventos de ratón y teclado sin procesar rara vez constituyen una automatización terminada. Macro Recorder Plus los convierte en una tabla de acciones que se pueden activar, etiquetar, reordenar y editar, además de permitir pasos manuales.

Cada flujo puede exportarse con sus dependencias, recursos, lanzador y notas de ejecución. Si resulta más práctico entregar un solo archivo, el mismo flujo puede generar un ejecutable de Windows mediante PyInstaller.

Las acciones secretas guardan el nombre de una variable de entorno, nunca la contraseña. De este modo las macros compartidas o archivadas no exponen credenciales.
