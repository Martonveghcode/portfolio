Habitro

Un sistema de aprendizaje diario optimizado para retener y aprender material escolar. Tiene seguimiento individualizado del rendimiento con SQLite y un flujo de estudio diario; en mi caso incluye gramatica espanola, catalan y ejercicios de matematicas que hago cada dia.

Una ficha estática indica si la respuesta de hoy es correcta, pero no muestra los errores recurrentes. Habitro guarda resultados e intentos anteriores por tipo de ejercicio para que las sesiones posteriores tengan memoria útil.

El módulo crea pequeños lotes, puede mezclar preguntas pendientes y muestra la solución solo cuando se solicita. El tamaño, el orden, el ejercicio actual y el historial se mantienen juntos para favorecer el ciclo de intentar, comprobar y revisar.

La aplicación actual utiliza React y Vite. La versión anterior en Streamlit sigue disponible para experimentación local y comparte la misma idea de práctica diaria estructurada con progreso guardado.
