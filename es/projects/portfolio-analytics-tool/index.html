Portfolio Analytics Tool

Portfolio Analytics Tool es un script en Python con yfinance, NumPy, Pandas y SciPy que construye carteras a partir de posiciones en acciones y analiza el rendimiento con Sharpe, Sortino, maximo drawdown, etc., ademas de generar una frontera eficiente y carteras optimizadas con visualizaciones en matplotlib. Mi mejor cartera actual tiene 1.74 de Sharpe y 2.52 de Sortino.

Una lista de posiciones no explica cómo se comportan juntas. La herramienta descarga precios, reconstruye la cartera ponderada y compara rendimiento con volatilidad, riesgo a la baja y drawdown máximo.

En vez de presentar una única respuesta optimizada, la vista de frontera representa miles de asignaciones candidatas. El color expresa el ratio de Sharpe y marca como referencia las carteras de máximo Sharpe y mínima volatilidad.

La optimización depende de la ventana histórica, los supuestos y las restricciones. Las carteras generadas sirven para comparar e investigar; no son instrucciones automáticas de inversión.
