Chess Anki Maker

Un editor local para crear tarjetas de ajedrez normales o interactivas, grabar secuencias de jugadas y exportar mazos listos para Anki.

El editor permite colocar, mover y quitar piezas, girar el tablero, dibujar flechas y guardar una secuencia ordenada de posiciones para aperturas u otras líneas.

El modo de entrenamiento registra el bando y la secuencia esperada; la tarjeta exportada comprueba las jugadas, anima la respuesta rival y permite reiniciar la línea.

Las tarjetas de estudio pueden ser normales o invertidas y usar un diagrama interactivo, una imagen fija o un GIF. La aplicación crea el tipo de nota y descarga un archivo .apkg listo para importar.
